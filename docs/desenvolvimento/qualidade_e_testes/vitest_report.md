# :material-test-tube: Relatório de Testes Unitários e Componentes (Vitest)

Abaixo você encontra o relatório iterativo e completo dos testes do frontend desenvolvidos com **Vitest** e **React Testing Library**, abrangendo:

- Testes de Componentes (Renderização e Comportamento)
- Testes Unitários de Hooks e Utilitários
- Testes de Acessibilidade (vitest-axe)
- Cobertura de Código (Coverage via V8)

!!! note "Nota"
    Os testes unitários focam nas validações visuais e de lógica de negócio client-side, independentemente de conexão de rede ou backend ativo.
